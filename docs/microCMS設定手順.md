# microCMS API設定手順（初回のみ）

登録済みのmicroCMSサービスに、以下の2つのAPIを作成してください。
管理画面の「＋コンテンツ（API）を作成」→「自分で決める」から作成します。

## 1. お知らせ API

- API名: `お知らせ` / エンドポイント: `news`
- 型: **リスト形式**
- APIスキーマ（フィールド）:

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| `date` | 日付 | 日時 | ✓ |
| `title` | タイトル | テキストフィールド | ✓ |
| `body` | 本文 | リッチエディタ | |

## 2. ブログ API

- API名: `院長ブログ` / エンドポイント: `blog`
- 型: **リスト形式**
- APIスキーマ（フィールド）:

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| `date` | 公開日 | 日時 | ✓ |
| `title` | タイトル | テキストフィールド | ✓ |
| `slug` | スラッグ(URL用・英小文字とハイフン) | テキストフィールド | ✓ |
| `legacyId` | 旧記事ID(移行用・通常は空) | 数値 | |
| `excerpt` | 抜粋(一覧に表示される文) | テキストエリア | |
| `categories` | カテゴリ(カンマ区切り) | テキストフィールド | |
| `tags` | タグ(カンマ区切り) | テキストフィールド | |
| `eyecatchPath` | アイキャッチ画像パス(例: ../images/xxx.jpg) | テキストフィールド | |
| `eyecatchAlt` | 画像の説明 | テキストフィールド | |
| `body` | 本文 | リッチエディタ | |

※ 無料枠のAPI数(3個)に収めるため、カテゴリ・タグは参照APIではなく
カンマ区切りテキストで運用します。

## 3. APIキーの権限

「サービス設定 → APIキー」で、既定のAPIキーに以下を設定:
- GET: 有効（ビルドが読み取りに使用）
- POST: 有効（初回のデータ移行時のみ必要。移行後は無効に戻してよい）

## 4. Claudeに共有するもの

- サービスID（管理画面URLの `xxxx.microcms.io` の xxxx 部分）
- APIキーの値

この2つを共有いただければ、既存のお知らせ27件・ブログ記事11件を
自動投入し、ビルドをmicroCMS連携に切り替えます。
