# スタッフの活動の更新方法

活動ページ：https://sakurai-crc.org/activities.html

## 活動報告を追加する

1. microCMSの「お知らせ」で記事を追加する。
2. タイトルの先頭に `【活動報告】` を付ける（例：`【活動報告】○○学会で発表しました`）。
3. 日付には掲載日を入力する。活動の開催日・発表日は本文に記載する。
4. 本文に活動年月、担当者名、学会・会場・雑誌名などと短い説明を記載する。必要に応じて写真や出典へのリンクを追加する。
5. 「公開」すると、既存の仕組みでお知らせと活動ページの両方に反映される。活動ページの見出しでは `【活動報告】` を省いて表示する。

通常のお知らせはタイトルにこのラベルを付けず、従来どおり掲載する。活動ページには全件の活動報告を新しい掲載日順に表示し、お知らせのトップ掲載期間を過ぎても残る。

活動報告が未登録の間は、ユーザー提供の「夏の雲」の院内展示を初期表示する。最初の活動報告を公開すると通常の活動一覧に切り替わる。展示の記録も残す場合は、同様に活動報告として登録する。

記事の編集・公開停止・削除は「お知らせ」と同じ画面から行う。ページのレイアウトや初期表示の変更はサイトのソースコードで管理する。
