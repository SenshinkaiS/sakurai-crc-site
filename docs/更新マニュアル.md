# ホームページ更新マニュアル（院内スタッフ向け）

## お知らせを追加・修正する

1. https://app.microcms.io にログイン
2. 左メニューの「お知らせ」を開く
3. 「＋追加」を押して、日付・タイトル・本文を入力
4. 右上の「公開」を押す
5. **約5分以内**にホームページへ自動反映されます
   （トップページには直近3ヶ月分、お知らせ一覧には全件表示）

修正・削除も同じ画面からできます。「公開」を押した時点で反映が始まります。

## ブログ記事を書く

1. microCMSの「院長ブログ」を開き「＋追加」
2. 入力項目:
   - **公開日**: 記事の日付
   - **タイトル**: 記事タイトル
   - **スラッグ**: 記事URLになる英語（例: `summer-heat-stroke`）。
     英小文字とハイフンのみ。日本語は使わないでください
   - **抜粋**: 一覧ページに表示される1〜2文
   - **カテゴリ / タグ**: カンマ区切り（例: `健康・医療, 心臓リハビリ`）
   - **アイキャッチ画像パス**: `../images/ファイル名.jpg`
     （新しい画像はClaude Codeセッションでimagesフォルダに追加してもらう）
   - **本文**: リッチエディタで自由に執筆（見出し・太字・リンク可）
3. 「公開」で送信。記事は `https://sakurai-crc.org/blog/posts/スラッグ.html` に公開されます

## 反映されないときは

1. 5〜10分待って、ブラウザで強制再読み込み（Mac: Cmd+Shift+R）
2. GitHubの Actions タブ（https://github.com/＜アカウント名＞/sakurai-crc-site/actions）で
   最新の実行が緑✓になっているか確認
3. 赤✗の場合や不明な場合は、Claudeのセッションで「サイトのデプロイが失敗しているので見てほしい」と相談

## 従来どおりClaude対応となるもの

- 診療時間・料金・スタッフ紹介など固定ページの変更
- 新しい画像の追加・最適化
- デザインの変更
